# Ограничения MVP

DevJobs находится на стадии готового backend MVP, а не публичного SaaS-запуска.

## Что уже есть

Backend реализует полный продуктовый путь: резюме, подтверждение профиля, анализ рынка, Career Market Fit, рекомендации, вакансии и roadmap. Для будущего интерфейса подготовлены screen-level API-контракты.

## Что не входит в текущий релиз

- Пользовательский frontend ещё не является самостоятельным публичным приложением.
- Нет публичного production-доступа к API.
- Внешние AI-провайдеры и HH требуют отдельной настройки секретов.
- Нагрузочное тестирование, production observability и независимый security audit не заявляются как завершённые.
- Реальные резюме и токены не используются в демонстрационных материалах.

## Обработка данных

В демонстрации используется локальный обезличенный набор данных. Для работы с реальными резюме нужны отдельные условия обработки данных, осознанная настройка внешних AI-провайдеров и privacy review.
