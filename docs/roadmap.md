# Статус и развитие продукта

## Сейчас

DevJobs находится в состоянии рабочего backend MVP. Реализован продуктовый путь:

```text
Резюме → Профиль кандидата → Анализ рынка → Career Market Fit
      → Рекомендации → План развития
```

Backend готовит данные для будущих пользовательских экранов и уже включает асинхронную обработку, интеграционный слой и проверки качества.

## Следующий этап

Приоритет — frontend, который превратит существующие screen-level API в цельный пользовательский продукт:

1. onboarding и загрузка резюме;
2. подтверждение профиля;
3. запуск и отображение прогресса анализа;
4. dashboard и Market Fit;
5. вакансии, roadmap и настройки.

## Дальнейшее развитие

- расширение объяснимости matching-оценок;
- наблюдаемость и production-метрики;
- security hardening;
- улучшение UX и визуализация карьерного пути;
- расширение источников вакансий и интеграций.

## Принцип развития

Публичный репозиторий показывает продуктовую эволюцию DevJobs. Реализация backend и чувствительная инфраструктура остаются приватными, чтобы не раскрывать исходный код, секреты и рабочие данные.
