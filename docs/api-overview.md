# Публичный обзор API

> Примеры ниже иллюстративны: они показывают формат продуктового взаимодействия и не являются открытым контрактом для production-доступа.

Backend уже предоставляет screen-level API для будущего frontend.

## Основные пользовательские экраны

| Экран | Назначение |
|---|---|
| Dashboard | Сводка по профилю, рынку и ближайшим действиям |
| Market Fit | Сильные стороны, пробелы и оценка соответствия рынку |
| Vacancies | Релевантные вакансии и причины совпадения |
| Roadmap | План развития навыков и ожидаемый эффект |
| Integrations | Статус подключений и обновление данных |
| Settings | Профиль, предпочтения и повторный запуск анализа |

## Пример сценария

```text
1. Пользователь загружает резюме или импортирует его из HH.
2. Backend формирует и возвращает профиль кандидата для подтверждения.
3. Пользователь запускает анализ рынка.
4. Worker собирает вакансии и рассчитывает результат.
5. Frontend запрашивает dashboard, market fit, vacancies и roadmap.
```

## Пример ответа dashboard

```json
{
  "profile": {
    "target_role": "Python backend developer",
    "target_level": "junior"
  },
  "market_fit": {
    "score": 64,
    "summary": "Есть базовое соответствие требованиям рынка."
  },
  "next_best_action": {
    "title": "Усилить SQL и тестирование",
    "expected_impact": "Повысит число релевантных вакансий"
  }
}
```

## Интеграции и данные

HH OAuth используется для пользовательских сценариев: подключение аккаунта, импорт выбранного резюме и обновление данных. Токены и персональные данные не публикуются в этом репозитории и не входят в примеры API.
